# Права проекта study-bot

Проект тот же, что в занятии 5: бот для конспектов. Код, заметки и общая папка входящих разделены, чтобы редактор конспектов не менял программу, а разработчик не удалял чужие файлы из входящих.

## Роли

| Роль | Учётная запись | Группы |
|---|---|---|
| руководитель | anna | bot-dev, bot-qa, sudo |
| разработчик | boris | bot-dev |
| редактор конспектов | vera | bot-qa |
| наблюдатель | oleg | только личная группа oleg |

## Каталоги

### 1. `/srv/study-bot/app`

- Владелец: root
- Группа: bot-dev
- Права буквами: `drwxrws---`
- Права числом: `2770`
- Почему так: код пишут anna и boris. setgid оставляет новым файлам группу `bot-dev`, а не личную группу автора. Остальным каталог закрыт, поэтому vera и oleg исходники не открывают.

### 2. `/srv/study-bot/notes`

- Владелец: root
- Группа: bot-qa
- Права буквами: `drwxrws---`
- Права числом: `2770`
- Почему так: заметки ведут anna и vera. Разработчик boris к конспектам не допускается. setgid сохраняет группу `bot-qa`.

### 3. `/srv/study-bot/inbox`

- Владелец: root
- Группа: bot-dev
- Права буквами: `drwxrws--T`
- Права числом: `3770`
- Почему так: сюда разработчики кладут вложения. Sticky-бит не даёт boris удалить файл anna, хотя у группы есть `w` на каталог.

## Файлы

### 4. `/srv/study-bot/app/bot.py`

- Владелец: boris
- Группа: bot-dev
- Права буквами: `-rw-rw-r--`
- Права числом: `664`
- Почему так: общий код. anna дописывает его как член `bot-dev`. Остальные только читают, если файл потом копируют в открытый каталог. Внутри `app` с правами `2770` «остальные» всё равно не доходят до файла.

### 5. `/srv/study-bot/app/token.env`

- Владелец: anna
- Группа: bot-dev
- Права буквами: `-rw-------`
- Права числом: `600`
- Почему так: токен бота. Даже boris из той же группы не должен его читать. Права закрыты явно, маска этого не гарантирует.

### 6. `/srv/study-bot/app/start.sh`

- Владелец: root
- Группа: bot-dev
- Права буквами: `-rwxr-x---`
- Права числом: `750`
- Почему так: скрипт запуска. Его выполняют anna и boris. Писать в него может только root, чтобы обычный разработчик не подменил команду запуска.

## umask команды

```bash
umask 0027
```

| Тип | База | Маска по тройкам | Права | Буквами |
|---|---|---|---|---|
| файл | `666` | владелец `6`, группа `6` без `w` → `4`, остальные `0` | `640` | `rw-r-----` |
| каталог | `777` | владелец `7`, группа `7` без `w` → `5`, остальные `0` | `750` | `rwxr-x---` |

Маска снимает у остальных все права и у группы запись. Секрет `token.env` всё равно закрывают отдельно до `600`: маска `0027` оставила бы группе чтение.

## Где нужен sticky-бит

Sticky-бит стоит на `/srv/study-bot/inbox`. Без него право `w` каталога позволяет любому члену `bot-dev` удалить чужой файл. С битом удалить файл могут его владелец, владелец каталога и root.

Отдельный ACL здесь не обязателен. oleg не входит в группы проекта, и каталоги для него закрыты нулём в последней тройке. Если позже ему понадобится читать только `notes`, не вступая в `bot-qa`, это уже запись ACL на один каталог, а не открытие его для всех остальных.
