Безопасные примеры относятся к `~/files-lab`. Опасные варианты в системе не запускались.

| Команда | Назначение | Безопасный пример | Опасный вариант и чем он опасен |
|---|---|---|---|
| `mkdir -p` | Создаёт каталог вместе с недостающими родителями и не ругается, если он уже есть | `mkdir -p ~/files-lab/sorted/docs` | `mkdir ~/files-lab/sorted/docs` без `-p` падает, если родителя ещё нет |
| `touch` | Создаёт пустой файл или обновляет время изменения | `touch ~/files-lab/inbox/notes.md` | `touch` с чужим путём затирает метку времени не того файла |
| `ls -A` | Показывает имена, включая скрытые, кроме `.` и `..` | `ls -A ~/files-lab/inbox` | `ls` без `-A` прячет `.settings`, его легко не заметить перед удалением |
| `cp` | Копирует файл, оригинал остаётся | `cp ~/files-lab/inbox/data.csv ~/files-lab/sorted/data/` | `cp data.csv ../backup/data.csv` без `-i` молча затирает уже существующую копию |
| `cp -n` | Копирует, но не заменяет существующий файл | `cp -n data.csv ../backup/` | `cp -f` заставляет замену даже если файл защищён от записи |
| `mv` | Переносит или переименовывает | `mv "my report.txt" my-report.txt` | `mv note.txt /tmp` без проверки уносит файл из рабочего каталога |
| `ln -s` | Делает символическую ссылку: в ней хранится путь, не содержимое | `ln -s note.txt note-link.txt` | `ln -sf` заменяет уже существующую ссылку без вопроса |
| `ls []` | Маска: один символ из набора в скобках | `ls photo-00[1-3].jpg` | `rm photo-00[1-5].jpg` удалит все совпадения, если заранее не посмотреть `ls` |
| `rm` | Удаляет файлы сразу, без корзины | `ls *.bak`, затем `rm -v *.bak` | `rm * .bak` — пробел перед `.bak` удаляет все файлы каталога |
| `rmdir` | Удаляет только пустой каталог | `rmdir old` после того, как каталог опустел | `rmdir` не удаляет каталог с файлами; `rm -rf /` стирает дерево без вопросов |
| `find` | Ищет по дереву каталогов | `find ~/files-lab -type f -mtime +30` | `find / -name "*.txt"` без ограничения каталога обходит всю систему |
| `find -delete` | Удаляет то, что нашёл `find` | `find ~/files-lab -type f -size +1M` и только потом `-delete` | `-delete` до проверки сотрёт лишнее |
| `locate` | Ищет путь по базе, а не по живому диску | `locate os-release \| head -1` | `locate` после удаления всё ещё показывает старый путь, пока не сделать `updatedb` |
| `man -k` | Ищет страницы справки по ключевому слову | `man -k ls \| head -2` | Путать с `man ls`: `-k` ищет описания, а не открывает страницу команды |
| `type` / `which` | Показывают, откуда берётся имя команды | `type ls` и `which ls` | `which` не видит встроенные команды оболочки так, как `type` |
